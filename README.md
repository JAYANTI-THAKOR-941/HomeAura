# HomeAura — Home Products Store

React storefront featuring product pages, cart, checkout, account screens and product administration, with Redux cart state.

## Project structure

- `src/pages/`
- `src/admin/`
- `src/redux/cartSlice.js`
- `db.json`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/HomeAura.git
cd HomeAura
```

Run `npm install`, configure any local API required by the app, then run `npm run dev`.
